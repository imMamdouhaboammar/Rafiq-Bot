# Code of Conduct

Rafiq welcomes technical disagreement and critical review. Participation must remain respectful, specific, and focused on the work.

## Expected conduct

Contributors should discuss code and decisions without personal attacks, harassment, discrimination, threats, sexualized conduct, doxxing, or deliberate disclosure of another person's private data. Assume good faith where evidence is incomplete, but challenge claims with reproducible evidence when correctness or security is at stake.

## Project spaces

This policy applies to repository issues, pull requests, discussions, review threads, project chat used for contribution work, and public interactions where someone is representing the project.

## Enforcement

Report conduct concerns privately to the repository maintainer through the maintainer's GitHub profile. Do not publish sensitive personal details in an issue. Maintainers may edit or remove content, close threads, restrict participation, or block contributors when necessary to protect the community and project.

Enforcement decisions should be proportional to the behavior, documented when practical, and separate from technical disagreement about the project.
