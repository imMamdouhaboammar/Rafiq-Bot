# Support

Rafiq is maintained as an open-source project. Use the repository's public support channels for reproducible project questions and keep secrets out of every report.

## Where to ask

- Bugs: use the GitHub bug report form and include the smallest reproducible case.
- Feature proposals: use the feature request form and explain the user problem before the implementation idea.
- Setup or contributor questions: use the question form and include the command that failed plus sanitized output.
- Security issues: follow `SECURITY.md`. Do not disclose a vulnerability in a public issue.

## Before opening an issue

Run `bun run typecheck`, `bun run test:p0`, and `bun run security:scan` when the local environment allows it. Search existing issues for duplicates. Remove API keys, cookies, service-account JSON, personal chat data, and private filesystem paths from logs or screenshots.

The project does not promise private one-to-one support or response-time SLAs. Maintainers may ask for a minimal reproduction before investigating environment-specific failures.
